# Esperanto - Interactive Language Learning Web Application

## 📌 Project Overview
This project is an **interactive web-based language learning platform** designed to help users improve vocabulary and grammar through engaging activities. It combines multiple mini-games and exercises to create a fun and effective learning experience.

The application is built using **HTML, CSS, and JavaScript**, focusing on simplicity, responsiveness, and real-time user interaction.

---

## 🎯 Features

### 🔤 Translation Exercises
- Practice **conjunctions, pronouns, and vocabulary translation**
- Instant feedback:
  - ✅ Correct answers → Green
  - ❌ Incorrect answers → Red

### 🔀 Anagram (Word Rearrangement)
- Rearrange scrambled words into correct vocabulary
- Improves spelling and word recognition

### 🔎 Word Search Game
- Interactive grid-based word search
- Click to highlight letters and discover hidden words
- Real-time validation with visual feedback

### 🧩 Crossword-style Learning
- Puzzle-based vocabulary exercises
- Enhances logical thinking and recall ability

### ⚡ Immediate Feedback System
- Dynamic validation using JavaScript
- Visual indicators (colors, checkboxes) for user progress
